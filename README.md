# TS Pensioners DA Arrears Calculator 40.04% | PPO ID

Telangana (TS/TG) Pensioners 40.04% DA/DR Arrears Calculator with PPO ID and Basic Pension support.

## Features
- Calculates month-wise DA/DR arrears for pensioners (RPS 2020)
- Support for 1st DA @37.31% (w.e.f Jan 2024) and 2nd DA @40.04% (w.e.f Jul 2024)
- Installment schedules & updated net pension summary
- Formulated and maintained by Nancharla Prudhvi, Senior Accountant, District Treasury, Khammam

## Run Locally
Double-click `start_server.bat` to launch the local web server at `http://localhost:5600/`.

## Push to GitHub
